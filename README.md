# TypeRed — Markdown Reader

版本：`0.3.3`
作者：Red

---

## 简介

TypeRed 是一个轻量级本地 Markdown 阅读/编辑器，用于替代 Typora 等付费工具。
基于 PySide6 + QWebEngineView，渲染效果接近 GitHub 风格。

## 功能

- 打开 `.md` / `.markdown` / `.mdown` / `.txt` 文件
- 拖拽文件直接打开
- 代码块语法高亮（Pygments）
- 自动生成目录（左侧可点击跳转）
- 5 种主题：默认 / 护眼 / 米黄 / 暗色 / 夜间
- macOS 风格交通灯按钮
- 分屏编辑 + 实时预览（Ctrl+E）
- Markdown 格式快捷键（粗体/斜体/标题/列表等）
- 最近文件、自动重载、页内搜索、导出 PDF、记忆窗口

## 使用方法

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python main.py

# 直接打开指定文件
python main.py path/to/file.md
```

## 快捷键

| 快捷键            | 功能                         |
|-------------------|------------------------------|
| `Ctrl+O`          | 打开文件                     |
| `Ctrl+S`          | 保存 / 另存为                |
| `Ctrl+R`          | 重新加载当前文件             |
| `Ctrl+P`          | 导出 PDF                     |
| `Ctrl+E`          | 切换编辑 / 阅读模式          |
| `Ctrl+T`          | 循环切换主题                 |
| `Ctrl+F`          | 页内搜索                     |
| `Ctrl+滚轮`       | 缩放页面                     |
| `Ctrl+B`          | 粗体（编辑模式）             |
| `Ctrl+I`          | 斜体（编辑模式）             |
| `Ctrl+1`~`Ctrl+6` | H1~H6 标题（编辑模式）       |
